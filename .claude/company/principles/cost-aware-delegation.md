# Cost-Aware Delegation

Agent turns, tokens, API calls and money are finite. Work expands to fill whatever budget is left open.

- Budget before delegating; if the estimate is too big, the scope is too big.
- Front-load context in the prompt. One long read is cheaper than rediscovery.
- Hard-cap scope per unit of work (files, items, dollars). Put caps in code where possible.
- Team coordination has overhead. Use one direct subagent before a team.
- Commit passing work before the budget runs out.
