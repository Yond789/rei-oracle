# Company Principles

Shared by every oracle in Companies A, B and C. Loaded automatically at session start by `inject-memory.sh`.
Adapted from poteto/brainmaxxing (MIT) and reconciled with the Oracle core principles.

| # | Principle | One line |
|---|-----------|----------|
| 1 | [prove-it-works](prove-it-works.md) | Verify the real thing, not a proxy or a self-report |
| 2 | [encode-lessons-in-structure](encode-lessons-in-structure.md) | A lesson that can be a hook, script, test or skill change must become one |
| 3 | [fix-root-causes](fix-root-causes.md) | Reproduce, find the cause, fix every instance of the pattern |
| 4 | [make-operations-idempotent](make-operations-idempotent.md) | Running twice, or after a crash, converges to the same state |
| 5 | [cost-aware-delegation](cost-aware-delegation.md) | Budget turns, tokens and money before delegating; cap scope |
| 6 | [guard-the-context-window](guard-the-context-window.md) | Every token in context must earn its place |
| 7 | [subtract-before-you-add](subtract-before-you-add.md) | Remove complexity first, then build |
| 8 | [boundary-discipline](boundary-discipline.md) | Validate at boundaries; keep logic in pure functions |

## Relation to Oracle core principles

- **Nothing is Deleted** wins over pruning: outdated memory is *moved* to `ψ/archive/`, never removed.
- **Patterns Over Intentions** is why principle 2 exists: written rules are intentions; hooks and scripts are patterns.
- **External Brain, Not Command**: humans keep all decisions. Each oracle's CLAUDE.md human-in-the-loop rules still apply.
