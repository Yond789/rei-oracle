# Encode Lessons in Structure

Textual instructions get skipped. Mechanisms (hooks, scripts, tests, lint rules, skill steps) enforce themselves.

- The second time you write the same instruction, ask: can this be a hook, script, test, metadata flag or skill change? If yes, build it and delete the instruction.
- If it genuinely needs judgment, keep it as text, make it prominent, and include an example of the failure.
- Every correction is a signal. Route it: one-off → learning note; recurring → skill/hook; systemic → principle.
- Close the loop: apply now or file a concrete todo. "I'll keep that in mind" persists nothing.

Evidence (2026-10-08): CLAUDE.md said "/rrr every session"; 4 of 6 surveyed oracles had zero retrospectives.
